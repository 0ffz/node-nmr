# Node editor

We provide a node graph system to quickly experiment with different denoising pipelines for a dataset,
inspired by [Blender's shader nodes](https://docs.blender.org/manual/en/latest/interface/controls/nodes/node_editors.html) and various [other programs](https://en.wikipedia.org/wiki/Node_graph_architecture)

## Introduction

Signal data flows along _links_ from _source nodes_, into _processing nodes_, ending in a graph node.
